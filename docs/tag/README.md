# TAG copies used in this project

Copies of the Transport Analysis Guidance (TAG) units that the notebook and `docs/methodology.md` cite. They are kept here so that the quotes can be checked against the text, and so that the page numbers in the notebook point to a known version.

Source for all files: the TAG index at https://www.gov.uk/transport-analysis-guidance-tag (Open Government Licence). Downloaded around 23 November 2026.
